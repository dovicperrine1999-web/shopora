# V15 Hover Grace Fix

The Account, Notifications, and Cart hover previews now remain open for **1.5 seconds after the cursor leaves** the control/preview area.

- Re-entering the control or preview cancels the close timer.
- Clicking the control still opens the full centered panel.
- Keyboard focus is respected so the preview does not disappear while navigating it with the keyboard.
- Applies consistently to Account, Notifications, and Cart.
